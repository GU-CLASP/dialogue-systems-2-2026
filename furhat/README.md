# Furhat & XState starter
To run:

1. Serve the audio by running the following command from the `furhat` directory:
```
npx http-server sounds -p 8000
```
2. Launch the furhat sdk and remote API
3. In a new CLI tab/window, run the following command from the `furhat` directory:
```
npx tsx src/main.ts
```
_______________________________
To run in watch mode:
```
npx tsx watch src/main.ts
```
