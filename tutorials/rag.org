* Run Qdrant using docker-compose
You will first need to install [[https://www.docker.com/products/docker-desktop/][Docker Desktop]]. 

In ~docker-compose.yml~:

#+begin_src yaml
services:
  qdrant:
    image: qdrant/qdrant:latest
    restart: always
    container_name: qdrant
    ports:
      - 6333:6333
      - 6334:6334
    expose:
      - 6333
      - 6334
      - 6335
    configs:
      - source: qdrant_config
        target: /qdrant/config/production.yaml
    volumes:
      - ./qdrant_data:/qdrant/storage

configs:
  qdrant_config:
    content: |
      log_level: INFO
      enable_cors: true  
#+end_src

Then:
#+begin_src sh
docker-compose up  
#+end_src

- different distance metrics (Dot, Cosine, Euclid, Manhattan)
- sparse vectors 
- multiple vectors for every point

* Calculate the embeddings using Ollama

Test it on mltgpu-2 (on other servers you need to ~pull~ the model first):
#+begin_src sh
ollama run qwen3-embedding "Hello"  
#+end_src

Or, in Typescript:
#+begin_src typescript
const embed = async (input: string) =>
  openai.embeddings
    .create({
      model: "qwen3-embedding",
      input: input,
      dimensions: 384,
    })
    .then((result) => result.data[0].embedding);
#+end_src

* Populate the collection
#+begin_src typescript
    const points = await Promise.all(
      menu.map(async (item, index) => {
        const embedding = await embed(item.join(" "));
        return {
          id: index,
          vector: embedding,
          payload: {
            name: item[0],
            note: item[1],
          },
        };
      }),
    );
    await client.upsert(name, { points });
#+end_src

* Integrating RAG into a dialogue system

Structure:
|                 | Subsection          |
|-----------------+---------------------|
| SYSTEM PROMPT   | General instruction |
|                 | Relevant Data       |
|-----------------+---------------------|
| MESSAGE HISTORY | Assistant           |
|                 | User                |
|                 | Assistant           |
|                 | User                |

#+begin_src typescript
    const gptresult = await openai.chat.completions.create({
      messages: [
        {
          role: "system",
          content: `
          You are a helpful restaurant assistant who helps selecting a menu item.
          Here are menu items selected specifically for user query:
          
          MENU START

          ${menuItems.join("\n")}
          
          MENU END

          Please be brief and do not mention anything which is not on the menu.
`,
        },
        {
          role: "assistant",
          content: "Hi, I am here to help! What do you fancy today?",
        },
        { role: "user", content: query },
      ],
      model: "llama3.2:latest",
    });  
#+end_src


In XState, you can create an actor:

    #+begin_src typescript
    queryRAG: fromPromise(async () => {
      const embedding = await openai.embeddings
        .create({
          model: "qwen3-embedding",
          input: "tofu",
          dimensions: 384,
        })
        .then((result) => result.data[0].embedding);
      return await client.query("foodItems", {
        with_payload: true,
        query: embedding,
      });
    }),
